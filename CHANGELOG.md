# Changelog

All notable changes to **Pomodrone** will be documented in this file.

## [1.0.0] - 2026-11-25

### Added
- **Drift-Free Timer Core:** Absolute timestamp countdown powered by an inline Web Worker and `visibilitychange` reconciliation.
- **Flowtime Mode:** Optional overtime counter upon focus completion to preserve deep-work flow.
- **Synthesized Web Audio Engine:** 4 procedural completion chimes (`bell`, `marimba`, `digital`, `gong`) and procedural `white`, `pink`, and `brown` ambient noise generators.
- **Material Design 3 UI & 3 Themes:** `AMOLED Pure Black (#000000)`, `Material Dark (#121214)`, and `Material Light (#F6F8FA)`.
- **Zero-Layout-Shift Bilingual Support:** Instant `VI` / `EN` toggling with `tabular-nums` metrics.
- **Task Drawer & Local Analytics:** Task Pomodoro estimation/tracking, daily streak counter, 7-day focus bar chart, 24-hour productivity heatmap, JSON backup/restore, and CSV export.
- **PWA & GitHub CI/CD:** Offline-first Service Worker (`sw.js`), Web App Manifest (`manifest.json`), PNG/SVG app icons, and GitHub Actions deployment workflows.
